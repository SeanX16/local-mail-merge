# Local Mail Merge v0.2.0-alpha

该预发布版完成了桌面界面的整体重构和批量审核基本功能闭环，可作为公司电脑上的基础功能测试版本。

## 更新内容

- 使用 shadcn/ui 组件和 Mira 视觉规范重构主界面、弹出菜单、导入弹窗与设置页；
- 使用虚拟化表格改善较大交接包的浏览性能，并完善整行选中高亮、复选框状态和列宽实时调整；
- 支持 Excel 导入时选择工作表与字段所在行，并提供可横向浏览的数据预览；
- 支持字段自由显示、逐列表头筛选，以及可创建、警告、已拦截三档内置校验结果；
- 完善 Outlook 账户、邮件签名及相关设置入口；
- 使用与应用设计语言一致的自定义标题栏和最小化、最大化、关闭窗口控件；
- 保持公司电脑安全边界：程序只创建并保存 Outlook 草稿，不自动发送邮件。

## 验证

- Core 回归测试 7/7 通过；
- Electron/TypeScript 生产构建和 Windows x64 正式打包通过；
- 打包后的 EXE 产品版本与文件版本均为 0.2.0；
- ZIP 内容检查通过，包含主程序、Outlook 工作进程、示例交接包和内置签名模板；
- 邮件执行路径检查通过，未引入自动发送或批量打开邮件窗口的调用。
