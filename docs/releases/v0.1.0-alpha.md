# Local Mail Merge v0.1.0-alpha

首个公司电脑试用预发布版。本版本使用 Electron + React/TypeScript 桌面界面，
由自包含 C# Worker 完成文件导入、分级校验和经典 Outlook COM 草稿保存。

## 主要功能

- 导入 JSON、CSV 和 Excel；Excel 可选择 Sheet 与字段行；
- 全量人员表格、自定义显示字段和 Excel 式列筛选；
- 点击人员行实时预览邮件；
- 区分可人工继续的警告与禁止创建的硬拦截；
- 选择已登录的经典 Outlook 账户和应用内公司模板；
- 只调用 `Save()` 保存 Outlook 草稿，不自动发送；
- 按批次、人员和内容哈希去重，并在本地保存审计结果。

## 已知限制

- 只支持 Windows x64 与经典 Outlook；
- 新 Outlook 不支持当前 COM 流程；
- 当前为未签名内部测试版，公司策略可能要求 IT 白名单或代码签名；
- 设置、已导入模板、去重记录和报告保存在当前 Windows 用户的 AppData，不保存在 ZIP 内。
