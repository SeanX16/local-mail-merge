# Local Mail Merge v0.1.1-alpha

该预发布版修复了经典 Outlook 草稿中纯文本正文的段落换行丢失问题。

## 修复内容

- 不再依赖 Outlook Word HTML 渲染器不支持的 `white-space: pre-wrap`；
- 将纯文本空行转换为显式 HTML 段落，将段落内换行转换为 `<br>`；
- 继续对纯文本中的 `<`、`>` 和 `&` 等字符执行 HTML 转义；
- 交接包本来就提供 `body_html` 时，保持原有 HTML 不变。

## 验证

- Core 回归测试 7/7 通过；
- Electron/TypeScript 生产构建通过；
- 免安装 ZIP 独立解压后 UI 交互冒烟测试 20/20 通过，控制台 0 错误；
- 发布包中的 Core DLL 与本次 Release 构建输出一致。
