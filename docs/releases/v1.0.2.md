# Local Mail Merge v1.0.2

这一版主要修复工作电脑实测时发现的两个问题：Outlook 草稿明明已经保存，却被应用提示为失败；以及部分 Excel 表头无法自动识别为邮箱字段。同时在“关于”页面加入了手动检查更新。

## 直接下载

- **[下载安装版](https://github.com/SeanX16/local-mail-merge/releases/download/v1.0.2/Local-Mail-Merge-v1.0.2-Setup.exe)**

  适合长期使用。安装向导中可以选择安装目录，并决定是否创建桌面和开始菜单快捷方式。

- **[下载便携版](https://github.com/SeanX16/local-mail-merge/releases/download/v1.0.2/Local-Mail-Merge-v1.0.2-Portable-win-x64.zip)**

  解压后直接运行，适合先在工作电脑上测试。

## 这次更新了什么

- 修复 Outlook 已成功保存草稿，却因为 COM 方法没有返回值而被误判为失败的问题。
- 将“草稿保存失败”和“保存后的编号、审计或报告写入警告”分开显示，结果提示更准确。
- 调整创建结果弹窗，让成功、警告和失败记录更容易区分和查看。
- 改进 Excel 邮箱字段识别：除了常见表头，还会结合表头关键词和单元格内容判断，因此“学生邮箱”“个人邮箱”“员工邮箱”等变体也能识别。
- 对状态、类型、备注等容易误判的字段增加排除规则；存在歧义时会请用户手动选择，不会擅自猜测。
- 手动选择过的邮箱字段会在后续校验和创建草稿时继续沿用。
- 在“关于”页面增加“检查更新”。只有用户主动点击时才会访问 GitHub，应用启动、打开关于页面和后台运行时都不会自动检查或提示。
- 应用内版本号及安装包版本号更新为 v1.0.2。

## 使用提醒

- 应用只把邮件保存到经典版 Outlook 的“草稿”文件夹，不会自动发送。
- 正式批量创建前，建议先用少量记录确认收件人、正文、附件和签名。
- 当前安装包尚未进行代码签名，Windows 或安全软件可能显示未知发布者提示。请从本仓库 Release 下载，并可用下方 SHA-256 校验文件完整性。
