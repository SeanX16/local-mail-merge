# Local Mail Merge v1.0.0

这是 Local Mail Merge 的第一个正式版本。它把已经审核好的 Excel、CSV 或 JSON 数据整理成可预览、可筛选的邮件列表，
并保存为经典 Outlook 草稿。应用不会自动发送邮件，最后仍由你在 Outlook 中逐封检查并手动发送。

## 下载哪个版本

- **安装版**：`Local-Mail-Merge-v1.0.0-Setup.exe`
  适合长期使用。双击后按提示安装，可以从 Windows 的“已安装的应用”中卸载。
- **便携版**：`Local-Mail-Merge-v1.0.0-Portable-win-x64.zip`
  适合不想安装或先在工作电脑测试。请完整解压到新文件夹，再运行 `LocalMailMerge.exe`，不要直接在压缩包内启动。

两种版本都是 Windows x64，并且都需要已经登录的经典桌面版 Outlook。由于目前没有代码签名证书，Windows 可能显示
SmartScreen 提示；请只从本 Release 下载，并用随附的 SHA-256 文件核对。

## 这个正式版包含什么

- 导入 Excel、CSV 和 JSON；Excel 可以在导入前选择工作表和表头行；
- 保留原始字段，支持表格筛选、自定义显示列、逐行勾选和右侧邮件预览；
- 明确选择 Outlook 发件账户和邮件签名，确认后批量保存草稿；
- 支持 `.html`、`.htm` 和 `.oft` 签名，包含图片打包、安全检查、预览、重命名和无收件人测试草稿；
- 支持本地配置拦截、警告和默认放行规则，并保护无效邮箱、重复人员和重复草稿；
- 完善创建结果、错误定位和本地报告；
- 新增正式的“关于”页面，显示 v1.0.0、作者、GitHub 和 MIT License；
- README 已改为日常使用指南，并新增一份给 AI 使用的数据准备与交接规范。

## 使用提醒

1. 第一次运行先用随包的 `.test` 虚构数据熟悉界面。
2. 导入真实数据后，确认发件账户、签名、收件人、主题和正文。
3. 黄色警告项需要主动选择，并在创建前再次确认。
4. 草稿创建完成后，到 Outlook 草稿箱逐封检查。
5. 应用不会自动发送，也不会在公司电脑上调用 AI。

完整使用方法见 [README](https://github.com/SeanX16/local-mail-merge/blob/v1.0.0/README.md)。需要让 AI 整理
Excel、JSON 或签名文件时，请把
[AI 数据准备与交接规范](https://github.com/SeanX16/local-mail-merge/blob/v1.0.0/docs/guides/AI数据准备与交接规范.md)
直接交给它。
