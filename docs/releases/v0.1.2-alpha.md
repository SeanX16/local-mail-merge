# Local Mail Merge v0.1.2-alpha

该预发布版完善了顶部交接包、Outlook 账户和邮件签名的显示与操作方式。

## 更新内容

- 交接包路径过长时从目录中部省略，完整保留末尾文件名；
- 将页面、设置、确认框和错误提示中的“公司模板”统一改为“邮件签名”；
- Outlook 账户改为与应用整体风格一致的自定义下拉菜单；
- 邮件签名改为自定义下拉菜单，并在底部分隔显示“添加新签名”；
- 点击“添加新签名”会直接打开设置中的邮件签名管理页。

## 验证

- Core 回归测试 7/7 通过；
- Electron/TypeScript 生产构建通过；
- 开发态 UI 交互冒烟测试 26/26 通过，控制台 0 错误；
- 免安装 ZIP 独立解压后版本号为 0.1.2，UI 交互冒烟测试 26/26 通过，控制台 0 错误；
- 1366 × 768 主界面、账户菜单、签名菜单和签名设置页视觉验收通过。
