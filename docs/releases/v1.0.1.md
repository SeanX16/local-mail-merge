# Local Mail Merge v1.0.1

这次更新换上了新的 Local Mail Merge 图标，并把 README 的界面截图更新为当前版本。应用的邮件处理逻辑没有改变：仍然只把邮件保存到经典 Outlook 草稿箱，不会自动发送。

## 直接下载

- **[下载安装版](https://github.com/SeanX16/local-mail-merge/releases/download/v1.0.1/Local-Mail-Merge-v1.0.1-Setup.exe)**
  适合长期使用。安装向导可以选择安装目录，以及是否创建桌面和开始菜单快捷方式。
- **[下载便携版](https://github.com/SeanX16/local-mail-merge/releases/download/v1.0.1/Local-Mail-Merge-v1.0.1-Portable-win-x64.zip)**
  适合免安装使用或先行测试。请完整解压后运行 `LocalMailMerge.exe`。

## 这次更新了什么

- 启用新的 LM 图标，并统一应用到主程序、安装器、窗口标题栏和“关于”页面；
- 更新 README 主界面截图，并补充字段显示与筛选操作截图；
- 应用内版本号及安装包版本号更新为 v1.0.1。

## 使用提醒

- 仅支持 Windows x64，需要已经登录的经典桌面版 Outlook；
- 目前发布物没有代码签名证书，Windows SmartScreen 或安全软件可能显示未知发布者提示；
- 请只从本项目的 GitHub Release 下载，并在需要时使用随附的 SHA-256 文件核对完整性。
