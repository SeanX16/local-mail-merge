# Local Mail Merge v0.1.3-alpha

该预发布版完善了批量审核表格的校验表达、列宽调整和弹层交互，并统一了当前界面的基础字号与控件密度。

## 更新内容

- 将内置校验结果固定渲染为绿色“可创建”、橙色“警告”和红色“已拦截”三档标签；
- 支持在表头拖动调整每列宽度，双击恢复默认宽度，并支持键盘微调；
- 表头筛选菜单支持点击页面空白处自动关闭，重复点击筛选按钮也可收起；
- 收敛主界面、邮件预览、导入弹窗和设置页的基础字号与主要控件尺寸；
- 打开设置页时，Electron 原生标题栏与窗口按钮区域同步压暗，关闭后恢复。
