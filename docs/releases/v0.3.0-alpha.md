# Local Mail Merge v0.3.0-alpha

该预发布版面向公司电脑继续进行功能测试，重点完善邮件签名的导入、检查、预览和实际使用流程，并补充审核界面的可配置能力。

## 更新内容

- 邮件签名支持 `.oft`、`.html` 和 `.htm`，导入时检查危险 HTML、预设收件人和普通附件；
- 导入 HTML 时自动打包同一文件夹内可读取的 PNG、JPEG、GIF 或 WebP 图片，缺失图片会明确拦截；
- 主界面和设置页显示当前签名的实际内容，支持固定高度的签名选择器、重命名和删除；
- 支持创建无收件人的签名测试草稿，用于在 Outlook 中核对 Logo、链接和最终排版；
- 邮件预览移除虚构附件信息，签名图片按正文内嵌资源处理；
- 邮件预览右上角信息支持从当前导入文件的字段中选择，选择会保存在本机；
- 完善本地校验规则配置、创建结果反馈、字段名称保留、表头筛选和界面交互一致性；
- 保持公司电脑安全边界：只创建并保存 Outlook 草稿，不自动发送，也不批量打开撰写窗口。

- Core 回归测试 11/11 通过；
