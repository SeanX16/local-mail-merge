## 已验证事实

- `.eml` 在公司电脑可编辑，但关闭后不会进入草稿箱；
- Outlook 本地自动化可编辑并保存到草稿箱；
- Graph Explorer 无法登录公司邮箱；
- 测试脚本调用 `Display()` 会打开窗口；批量正式流程必须只 `Save()`；
- 公司电脑最初禁止直接运行未签名 PowerShell，正式交付不应依赖用户修改执行策略。

## 第一个开发目标

实现三人虚构数据 MVP：

- 固定并校验 `outreach-package/v1`；
- 明确选择 Outlook 发件账户；
- 逐封预览并人工勾选；
- 批量创建三封不弹窗草稿；
- 保留公司签名；
- 通过 `batch_id + person_id + content_hash` 防止重复；
- 不存在 `Send()`、`sendMail` 或 Graph 发送路径；
- 输出不含凭据的本地成功/失败报告。
